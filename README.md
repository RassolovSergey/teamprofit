# TeamProfit

**Учебное командное приложение для управления проектами и их финансами.**

## Возможности в коде

- Проекты и участники.
- Доходы, расходы, продажи и вознаграждения.
- Валюты и обновление курсов.
- Авторизация и проверка доступа участников к проектам.
- Веб-интерфейс на Blazor.

## Стек

C#, ASP.NET Core, Blazor, Entity Framework Core, реляционная БД.

## Структура

- `ClientPart`: интерфейс и клиентские сервисы.
- `Server`: API, авторизация и фоновые операции.
- `Data`: сущности, конфигурации и контекст БД.

## Статус

Курсовая командная работа. Личный вклад участников и воспроизводимый порядок запуска требуют отдельного описания, поэтому здесь не приписывается весь проект одному автору.

Перед публикацией и внешним запуском необходимо проверить конфигурацию: значения ключей, паролей и строки подключения должны задаваться локально. Если использованный ранее внешний API-ключ был настоящим, его нужно заменить у провайдера. Удаление значения из последней версии не удаляет историю Git.

Более поздняя работа с проектными финансами представлена в IS Budget.
