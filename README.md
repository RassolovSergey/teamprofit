# TeamProfit

**Самостоятельный учебный проект для управления проектами и их финансами.**

## Возможности в коде

- Проекты и участники.
- Доходы, расходы, продажи и вознаграждения.
- Валюты и обновление курсов.
- Авторизация и проверка доступа участников к проектам.
- Веб-интерфейс на Blazor.

## Стек

C#, ASP.NET Core, Blazor, Entity Framework Core, реляционная БД.

## Структура

- `ClientPart`: интерфейс и клиентские сервисы.
- `Server`: API, авторизация и фоновые операции.
- `Data`: сущности, конфигурации и контекст БД.

## Статус

Проект самостоятельно разработан Сергеем Рассоловым в рамках обучения. Приложение предназначено для учёта проектов, участников и финансов.

## Локальная конфигурация

Ключи и строка подключения в публичном `appsettings.json` оставлены пустыми. Для разработки используйте .NET User Secrets или переменные окружения. [Инструкция по настройке](docs/local-configuration.md).

Более поздняя работа с проектными финансами представлена в [IS Budget](https://github.com/RassolovSergey/is-budget).
